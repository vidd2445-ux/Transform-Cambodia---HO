Your browser has blocked location access. To re-enable GPS for accurate geofence checking:

  • ⚠ HTTPS required: GPS geolocation only works over HTTPS or localhost. If you are on http://, switch to https:// — browsers silently block geolocation on plain HTTP.
  • Chrome (Android/Desktop): Lock/⚡ icon → Site Settings → Location → Allow
  • Safari (iOS): Settings → Privacy & Security → Location Services → Safari Websites → While Using
  • Safari (macOS): Safari → Preferences → Websites → Location → Allow
  • Firefox: Location icon in address bar → Clear "Block" → Reload
  • Samsung Internet: Settings → Sites and downloads → Location permissions → Allow

After changing the setting, reload this page or tap Retry GPS.
